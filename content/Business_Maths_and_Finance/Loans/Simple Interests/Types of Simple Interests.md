Here are many ways simple interests can be **characterized**. 

| Umbrella Term    | Sub-terms                         | Definition                                 |
| ---------------- | --------------------------------- | ------------------------------------------ |
| Duration Markers | Origin Date                       | Starting date of the loan                  |
|                  | Maturity Date                     | Ending date of the loan                    |
| Year Definition  | Ordinary Interest (Banker's Rule) | $$\frac{\text{Number of days}}{365}$$      |
|                  | Exact Interest                    | $$\frac{\text{Number of days}}{365}$$      |
| Term Definition  | Approximate Time                  | **Assumption** that each month has 30 days |
|                  | Actual Time                       | **Exact** number of days per month         |
