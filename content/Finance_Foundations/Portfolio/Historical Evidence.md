History allows us to **quantify** [[Risk|risk]] and establish a baseline for expected [[return]]. It provides the **standard deviation** (volatility) to measure uncertainty.^utility-historical-evidence

| Asset Type           | Avg Nominal Return | Risk Level |
| -------------------- | ------------------ | ---------- |
| [[Treasury Bills]]   | 3.8%               | Very Low   |
| [[Government Bonds]] | 5.3%               | Moderate   |
| Common [[Stocks]]    | 11.5%              | High       |
|                      |                    |            |
<center><b>Table 7.1</b> Average rates of return on U.S. Treasury Bills, government bonds, and stocks, 1900-2017</center>

By definition, treasury bills are risk-free, so excess earned by stocks is **risk premium**.^def-risk-premium ^0f15ab

$$
\text{Risk Premium} = 11.5\% - 3.8\%=7.7\%
$$
