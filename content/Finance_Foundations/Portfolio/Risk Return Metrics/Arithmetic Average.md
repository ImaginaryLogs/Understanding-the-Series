Used to answer the generally question: 
> "*Historically, what is the typical result in any given year for this asset?*"

It is given by the equation:
$$
A_{mean} = \frac{r_1 + r_2 + \cdots + r_n}{n}
$$

It measures the **cost of capital** aka the cost of buying to an investment.

# Real world application
Imagine you have ₱1,000,000 to invest. You are choosing between Investment A (a volatile Tech Stock) and Investment B (a stable Index Fund).

| **Year**   | **Investment A (Tech Stock)** | **Investment B (Index Fund)** |
| ---------- | ----------------------------- | ----------------------------- |
| **Year 1** | +40%                          | +10%                          |
| **Year 2** | -30%                          | +10%                          |
| **Year 3** | +50%                          | +10%                          |
Then, the expected return for any year is given by the arithmetic average. 
- **Investment A:** $(40 - 30 + 50) / 3 = \mathbf{20\%}$
 - **Investment B:** $(10 + 10 + 10) / 3 = \mathbf{10\%}$

As a financial manager, your best guess would be going with investment A as has the best guess for a single-period forecast.
